# ADR Estrutura Inicial - Arquitetura da API

## Status
Aceito

## Contexto

A API necessita de uma estrutura de pastas robusta que facilite a manutenção.

## Decisão

Será utilizada a arquitetura modular

## Consequências

### Positivas

- escalabilidade
- fácil manutenção
- isolamento de funcionalidades

### Negativas

- dificuldade na reutilização de código entre módulos
